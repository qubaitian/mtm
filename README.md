# mtm

MTM means Mini Terminal Multiplexer.  
It keeps Session management, Service management, and Passthrough transport.  
Use a Common Lisp SBCL and Quicklisp.

Run the test suite from the repository root.  

```sh
sbcl --noinform --non-interactive --eval '(asdf:test-system "mtm")'
```

Run the command from the repository root.  

```sh
./bin/mtm --help
```
